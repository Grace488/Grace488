## 💫 About Me

I am a final-year **Informatics Engineering student at Universitas Lampung** with a specialized focus on **Backend Architecture**, **Full-Stack Web Development**, and emerging technologies including **AI Agent Workflows** and **Web3 systems**.

Combining a strong engineering foundation with hands-on **UI/UX design** capability, I build web solutions that balance system reliability, clean relational database architecture, and user-centered design. Currently completing my undergraduate thesis by developing **UNILA Care**, a production counseling and mental health management ecosystem serving the Universitas Lampung academic community.

- 🎓 **Academic**: Final-Year B.S. in Informatics Engineering @ **Universitas Lampung**
- 💻 **Core Engineering**: Scalable RESTful APIs, Relational Database Modeling, and Modern Web Architectures
- 🤖 **Emerging Tech**: AI Agent Training & Fine-Tuning Workflows, Web3 Smart Contract Integrations
- 🎨 **Creative Dimension**: End-to-end UI/UX prototyping (Figma/Framer) & Brand Visual Identity
- 📌 **Thesis Project**: Architected [UNILA Care](https://grace-yoelanda-turnip.vercel.app/) (deployed counseling platform at `upa-bk.unila.ac.id`)
- ⚡ **Interests**: Pixel-art games, gamified edtech platforms, and high-performance backend systems
